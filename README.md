# 📦 Inventory Management API  

## ⚙️ Funcionalidades  

- Cadastro e gerenciamento de **Categorias**  
- Cadastro e gerenciamento de **Produtos**  
- Controle de **Clientes**  
- Registro de **Pedidos** e **Itens do Pedido**  
- Movimentação de **Estoque** (entrada e saída de produtos)  
- Padrão **Unit of Work + Repository** implementado  
- Documentação e testes com **Swagger**  

---

## 🛠️ Ferramentas  

- .NET 6 / 7 (ASP.NET Core Web API)  
- C#  
- PostgreSQL (armazenamento de dados)  
- Dapper (acesso ao banco de dados)  
- Swagger (documentação da API)
